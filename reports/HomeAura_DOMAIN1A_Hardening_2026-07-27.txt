========================================================================
4. OLD COLLISIONAL REPRESENTATION
========================================================================

The first DOMAIN-1 implementation used delimiter-joined strings, for
example:

project|project_id|{project_id}|drawing|{drawing_name}

These two distinct inputs produced the same name:

Input A:
project_id = "a|drawing|b"
drawing_name = "c"

Input B:
project_id = "a"
drawing_name = "b|drawing|c"

Old name for both:

project|project_id|a|drawing|b|drawing|c

The same general ambiguity applied whenever caller-controlled
components contained delimiter-like text.

The old scheme is no longer used.

5. NEW COLLISION-SAFE REPRESENTATION

One shared helper now creates the UUIDv5 name:

        1,
        entity_type,
        *canonical_components,
    ],
    ensure_ascii=False,
    separators=(",", ":"),
    allow_nan=False,

b62d9c24-0c2f-5e2a-8c7d-2d4bb9c98772

- no join;
- no repr;
- no OS-dependent representation;

The serialized helper prefix is:
