6. ЗАПУСК СЛЕДУЮЩЕЙ СЕССИИ CLAUDE CODE
НЕ ВЫПОЛНЕНО. РЕШЕНИЕ, ПРИНЯТОЕ СОЗНАТЕЛЬНО: в HomeAura нет проверенного,
безопасного механизма для одного Claude Code процесса программно
запустить второй полностью автономный процесс на основе текста,
полученного из веб-ответа. Это качественно иной уровень риска, чем любое
разрешённое до этого действие — агент, порождающий новых
автономных агентов из внешнего, не полностью доверенного текста, без
участия человека в контуре. Реализация такого лаунчера не была
санкционирована отдельно ни владельцем, ни этим этапом настолько явно,
чтобы оправдать реальный риск.
НЕЗАВИСИМОЕ ПОДТВЕРЖДЕНИЕ: сам извлечённый ответ ChatGPT (раздел 4)
самостоятельно, без подсказки с моей стороны, включает в
PROHIBITED ACTIONS пункт "start another Claude Code session from Bridge
output" и явно пишет "Do not automatically start another implementation
stage from the returned text" — то есть независимый архитектурный обзор
пришёл к тому же выводу. Вместо запуска нового процесса: задача
поставлена в SQLite (раздел 5), извлечённый промт сохранён как artifact
(`task_artifacts`, kind=`next_prompt`), доступен для ручного или будущего
контролируемого запуска.
