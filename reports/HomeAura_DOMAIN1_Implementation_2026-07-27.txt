7. LIMITED STABILITY OF DERIVED PROJECT ID
========================================================================

The Project UUID is deterministic for the same canonical project_id and
DrawingName, but it is not an immutable external identity.

Renaming the project or drawing changes the UUID. Therefore:

- Project source.kind is derived_deterministic;
- Project validation_status is requires_confirmation;
- the unassigned Building and Level are legacy_placeholder;
- both placeholders are requires_confirmation;
- a later reviewed vertical must introduce authoritative hierarchy
  identities before persistence or cross-project references.

A unique SourceHandle validates room identity within the current
derived drawing context. A Code fallback is only allowed when Handle is
missing and is requires_confirmation.

Empty fallback keys, duplicate normalized fallback Codes and duplicate
normalized SourceHandles raise controlled DomainAdaptationError
exceptions.

IfcSpace.GlobalId is an alias/source evidence only. It never replaces
the room stable_id.
