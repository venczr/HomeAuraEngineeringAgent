3. РЕАЛИЗОВАННЫЙ КОНТРАКТ BOUNDARY
========================================================================

Boundary содержит:

- SourceHandle — Handle исходного объекта AutoCAD;
- SourceObjectType — DXF-тип исходного объекта;
- SourceLayer — слой исходного объекта;
- Vertices — нормализованный список вершин XYZ;
- Vertices[].Bulge — bulge исходящего сегмента;
- Vertices[].SegmentType — Line или Arc;
- IsClosed — признак логической замкнутости;
- ContourAreaDrawingUnits2 — площадь в единицах DWG²;
- ContourAreaM2 — площадь в квадратных метрах;
- PerimeterDrawingUnits — периметр в единицах DWG;
- PerimeterM — периметр в метрах;
- OriginalDirection — исходное направление CW/CCW;
- Direction — нормализованное направление;
- DrawingUnits — единицы Database.Insunits;
- MetersPerDrawingUnit — коэффициент перевода в метры;
- GeometrySource — источник геометрии;
- Diagnostics — результаты проверки и диагностические сообщения.

Старое поле NetAreaM2 сохраняет прежний смысл: это площадь, полученная
из бинарных данных маркера MagiCAD.

Для явного обозначения источника добавлено поле:

    MagiCadNetAreaM2

Вычисленная площадь AutoCAD хранится отдельно:

    Boundary.ContourAreaM2

Также добавлены:

    BoundaryAreaDifferenceM2
    BoundaryAreaDifferencePercent

Старые rooms.json без Boundary продолжают читаться Python API.

4. ПОДДЕРЖИВАЕМАЯ ГЕОМЕТРИЯ
========================================================================

В качестве границы помещения поддерживается только:

    Autodesk.AutoCAD.DatabaseServices.Polyline
    DXF-тип: LWPOLYLINE
    Условие: Polyline должна быть замкнута
    Расположение: пространство модели

Обнаруживаются, но не используются как контур:

- открытые Polyline;
- Polyline2d;
- Polyline3d;
- Region;
- геометрия внутри блоков на слоях MAGI*.

Для неподдерживаемых типов создаётся только диагностика. Искусственные
контуры не строятся.


========================================================================
5. ОБРАБОТКА ГЕОМЕТРИИ
========================================================================

Реализованы:

1. Чтение точных XYZ и bulge каждой вершины AutoCAD Polyline.

2. Удаление последовательных дубликатов вершин.

   Допуск:

       0,1 мм

   Допуск переводится в текущие единицы DWG.

3. Явное логическое замыкание.

   Первая вершина не дублируется в конце массива. Замкнутость задаётся
   полем IsClosed и последним сегментом к первой вершине.

4. Проверка минимального количества вершин.

       Минимум: 3 различные вершины

5. Проверка самопересечений.

6. Нормализация направления.

   Итоговый валидный контур нормализуется до CCW. При развороте
   корректно меняются направление и знак bulge дуговых сегментов.

7. Поддержка дуговых сегментов.

   Площадь и периметр не аппроксимируются — используются точные:

       AutoCAD Polyline.Area
       AutoCAD Polyline.Length

8. Дискретизация дуг для point-in-polygon и диагностики пересечений.

   Максимальное отклонение хорды:

       1 мм

   Этот допуск экспортируется в Diagnostics в единицах DWG.

9. Point-in-polygon для позиции маркера MagiCAD.

10. Выбор минимального содержащего контура.

    Если маркер находится внутри нескольких валидных контуров,
    выбирается контур с минимальной точной площадью.

11. Диагностика:

    - валидность контура;
    - неподдерживаемый тип;
    - отсутствие замыкания;
    - недостаточное число вершин;
    - удалённые дубликаты;
    - самопересечения;
    - неизвестные единицы;
    - отсутствие подходящего контура;
    - несколько содержащих контуров;
    - расхождение площади MagiCAD и AutoCAD.

12. КОМАНДЫ ДЛЯ ПРОВЕРКИ В AUTOCAD
========================================================================

1. Загрузить DLL:

       NETLOAD

   Временная DLL:

       C:\Users\zahar\AppData\Local\Temp\
       HomeAura-room-geometry-verification\
       plugin-bin\HomeAura.AutoCAD.Agent.dll

   Если AutoCAD блокирует DLL из временной папки, добавить эту папку
   в Trusted Locations AutoCAD. Для постоянной установки следует
   использовать отдельную доверенную папку плагинов.

2. Проверить плагин:

       HA_STATUS

   Ожидаемая версия:

       1.2.0.0

3. Проверить Python API:

       HA_API_STATUS

   Ожидаемая версия:

       0.6.0

4. Выполнить read-only диагностику:

       HA_DISCOVER_ROOM_BOUNDARIES

5. Проверить найденные:

   - Handle;
   - тип;
   - слой;
   - замкнутость;
   - площадь;
   - маркер внутри;
   - диагностические сообщения.

6. Экспортировать помещения:

       HA_EXPORT_ROOMS

7. Проверить новый rooms.json:

   - FormatVersion = 1.1;
   - NetAreaM2;
   - MagiCadNetAreaM2;
   - Boundary;
   - Boundary.ContourAreaM2;
   - Boundary.PerimeterM;
   - Boundary.Vertices;
   - Boundary.Diagnostics;
   - BoundaryAreaDifferenceM2;
   - BoundaryAreaDifferencePercent.

8. Проверить синхронизацию:

       HA_SYNC_ROOMS
