5. ЗАЩИТА ENDPOINT
========================================================================

Loopback:
  - IPv4 127.0.0.0/8 разрешён;
  - IPv6 ::1 разрешён;
  - IPv4-mapped loopback разрешён;
  - non-loopback получает 403 local_access_required;
  - testclient разрешён только для in-process integration tests.

Project registry:
  - project_id должен быть одним простым именем;
  - каталог projects разрешается через resolve(strict=True);
  - проект должен существовать как directory;
  - разрешённый project root после resolve должен оставаться внутри
    зарегистрированного projects root;
  - неизвестный project_id получает контролируемый 404.

Paths:
  - absolute paths запрещены;
  - drive/anchor запрещены;
  - .. запрещён;
  - null byte запрещён;
  - существование проверяется;
  - directory вместо файла запрещён;
  - итоговый resolved path должен оставаться внутри resolved project root;
  - выход через symlink/junction после resolve даёт 400
    path_outside_project.

Extensions:
  - IFC: только .ifc, case-insensitive;
  - rooms: только .json, case-insensitive.

File limits:
  - IFC: 50 MiB, 52,428,800 bytes;
  - rooms JSON: 10 MiB, 10,485,760 bytes;
  - пустой файл запрещён;
  - превышение лимита даёт 413 input_file_too_large.

Read-only:
  - endpoint вызывает run_import(..., analyze_only=True);
  - output path отсутствует в модели запроса;
  - extra fields запрещены Pydantic-моделью;
  - попытка передать output_path даёт 422;
  - preview module не содержит write_text, write_bytes или mkdir;
  - Boundary не заменяется.

IfcOpenShell:
  - остаётся lazy optional dependency;
  - API startup не импортирует IfcOpenShell;
  - отсутствие пакета даёт 503;
  - machine code: ifcopenshell_unavailable.

Diagnostics:
  - unsupported возвращается как GeometryStatus=unsupported;
  - ambiguous остаётся diagnostic result;
  - unmatched остаётся diagnostic result;
  - эти состояния не маскируются как transport error.

Errors:
  - 400: invalid project/path/extension/containment;
  - 403: non-loopback;
  - 404: unknown project or missing input;
  - 413: oversized input;
  - 422: empty/damaged/invalid IFC or JSON, request validation;
  - 503: IfcOpenShell/project registry unavailable;
  - 500: контролируемая generic failure без traceback в response.

Все прикладные ошибки используют machine-readable detail.code и не включают
абсолютные локальные пути.

12. РИСКИ
========================================================================

1. У основного API в целом нет authorization middleware. Новый endpoint
   защищён loopback dependency, но остальные старые routes сохраняют прежнюю
   модель и могут стать внешне доступными при нестандартном запуске uvicorn.

2. Глобального ASGI body-size middleware нет. Preview request содержит только
   две Pydantic-строки максимум по 512 символов, но сервер разбирает JSON до
   model validation. Для локального endpoint риск мал; глобальный limit лучше
   решать отдельной задачей для всего API.

3. Между path validation и последующим открытием файла остаётся небольшой
   TOCTOU window. Endpoint локальный и read-only; resolved containment и
   file-type checks существенно снижают риск. Полное устранение потребовало бы
   передачи уже открытых handles или platform-specific file identity checks.

4. Реальный исследовательский IFC содержит одно простое помещение без holes.
   Сложные profiles/holes/placements остаются покрыты синтетическими тестами.

5. Настоящий Windows symlink/junction test заблокирован правами песочницы;
   containment logic покрыт детерминированной подменой resolved path.

6. TestClient deprecation warning требует будущего согласованного обновления
   тестового HTTP adapter, но устанавливать новые зависимости в этом этапе
   запрещено и не требуется.
