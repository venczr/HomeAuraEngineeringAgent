4. ENDPOINT ARCHITECTURE
======================================================================

Method and path:

POST /api/v1/rooms/domain/preview

The endpoint is implemented in a new APIRouter with prefix:

/api/v1/rooms

Registration in agent/api.py is limited to one import and one include_router.
API version remains 0.6.0.

Request envelope:

{
  "project_id": "Test_01",
  "rooms_payload": {
    "FormatVersion": "1.0",
    "DrawingName": "Test_01.dwg",
    "Rooms": []
  }
}

DomainPreviewRequest is strict:

- extra fields forbidden;
- project_id is a strict string from 1 to 128 characters;
- rooms_payload is a required JSON object.

project_id is not a URL path parameter and is never resolved as a file path.

The endpoint calls only the public adapt_rooms_payload DOMAIN-1 function.
It returns the strict DomainDocument response model.

The route does not:

- access the project registry;
- read rooms.json;
- read or write any project file;
- create a report or history file;
- call the IFC importer;
- open a network connection;
- run a subprocess.

The existing room, snapshot, analyze, and IFC preview routes were not edited.

======================================================================
5. LOOPBACK AND BROWSER-TO-LOCALHOST DEFENSE
======================================================================

The route calls the existing IFC preview direct-client loopback check and
maps its rejection to the fixed DOMAIN error code loopback_required.

Only Request.client is used. Forwarded and X-Forwarded-For are ignored.

Content-Type is checked before reading the body:

- application/json is accepted;
- application/json with only charset=utf-8 is accepted;
- missing Content-Type is rejected;
- text/plain is rejected;
- form and multipart content are rejected;
- any other media type or charset is rejected.

This blocks simple browser form and no-CORS text/plain requests before JSON
processing. A cross-origin application/json request requires browser
preflight, while the API has no permissive CORS middleware.

======================================================================
6. RAW BODY LIMIT BEFORE PYDANTIC
======================================================================

Limit:
10 * 1024 * 1024 raw bytes

The endpoint declares Request only and does not declare a normal Pydantic body
parameter. It does not call request.body() or request.json().

Raw Content-Length handling:

- reads request.scope headers directly;
- accepts zero or one Content-Length;
- rejects repeated equal or conflicting values;
- accepts only non-empty ASCII digits;
- rejects empty, signed, negative, spaced, comma-joined, and non-ASCII values;
- compares normalized decimal bytes safely before integer conversion;
- handles an extremely long digit string without Python integer-limit errors;
- rejects a declared value over 10 MiB before reading the body.

Streaming handling:

- reads Request.stream() incrementally;
- counts actual raw bytes independently of Content-Length;
- stops as soon as actual bytes exceed 10 MiB;
- enforces the same limit when Content-Length is missing;
- enforces the actual limit when the declared length is smaller;
- permits a valid body exactly at the limit.

After the byte limit:

- strict UTF-8 decoding;
- duplicate JSON keys rejected at any nesting level;
- NaN, Infinity and -Infinity rejected;
- top-level array, string, number, boolean or null rejected;
- malformed JSON and RecursionError mapped to safe HTTP 400;
- DomainPreviewRequest validation occurs only after these checks.

The OpenAPI operation contains an explicit required application/json
requestBody schema titled DomainPreviewRequest. HTTP 200 references the
DomainDocument response schema.

======================================================================
7. SAFE ERROR CONTRACT
======================================================================

Every DOMAIN preview error has:

{
  "detail": {
    "code": "stable_machine_code",
    "message": "safe fixed message"
  }
}

HTTP and code matrix:

400  domain_payload_invalid
Malformed length, UTF-8, JSON, duplicate key, non-finite number, recursion,
or non-object top level.

403  loopback_required
Direct client is not loopback.

413  domain_payload_too_large
Declared or actual body exceeds 10 MiB.

415  domain_content_type_invalid
Content-Type is missing or not the allowed JSON form.

422  domain_request_invalid
Strict envelope validation failed.

422  domain_rooms_payload_invalid
The legacy rooms payload could not be adapted.

422  unsafe_identity_path
Used only when DomainAdaptationError.code is exactly unsafe_identity_path.

500  domain_preview_failed
Unexpected parser, stream, validation, or adapter failure.

The implementation does not return or search exception text. It does not
return traceback, ValidationError.errors(), input values, project_id,
DrawingFullPath, path basename, drive, share, file URI, environment value, or
credential-shaped supplied text.
