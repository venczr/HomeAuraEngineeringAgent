## Как интерпретировать сбои

- HTTP 502 — ошибка вызова через шлюз; по ней нельзя оценивать интеллект модели.
- Три ответа завершились `length` при установленном `max_tokens=1024`.
  Это ограничение данного запроса/обвязки, не сообщение об исчерпании тарифа.
  Увеличение лимита не выполнялось: каноническая обвязка сейчас ограничивает
  резерв ответа 1024 токенами.
- Все 10 запросов получили сохранённое конечное состояние. Повторов и
  новых API-веб-чатов не создавалось. Для каждого помощника сохранена отдельная
  локальная история запроса и ответа.
- `reasoning_effort=max` подтверждён и передан только для GPT-5.6 Sol. Для
  остальных использованы настройки провайдера и просьба о максимальном
  рассуждении в тексте; программный режим max для них не подтверждён.
