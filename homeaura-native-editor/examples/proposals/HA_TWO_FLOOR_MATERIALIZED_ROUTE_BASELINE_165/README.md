# D165 · материализованные трассы

D164 сохранён как исторический body-only вариант. D165 возвращает в редактор реальные непрерывные оси: 12 полных K1→улитка→K1 на первом этаже и 11 осей второго этажа от подъёма до спуска. Никакой скрытой длины в JSON нет. Связь K2 с точками подъёма ещё не дорисована и не выдана за готовую.
