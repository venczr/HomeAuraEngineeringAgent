# D183 · три непрерывных Point3-маршрута кухни-гостиной

D183 изменяет относительно официального D181 только C07–C09. BODY полностью совпадает с проверенным D182; добавлены непрерывные многоуровневые TRANSIT-связи, не считающиеся отопительным покрытием. Все изменения высоты оформлены S-изгибами R80.

Физические R80-длины: 71.237 / 70.616 / 71.819 м; разброс 1.204 м. Покрытие BODY: 96.689%, максимум 200 мм, превышений нет. Все 25 касаний wall-solid, включая терминальные касания, принадлежат TRANSIT и перпендикулярны стенам.

Физические XYZ-хвосты от терминальной сетки до Eurocone не материализованы. Поэтому коллекторно-непрерывных маршрутов и complete K1 routes по-прежнему 0; гильзы не добавлены; installation_ready=false.
