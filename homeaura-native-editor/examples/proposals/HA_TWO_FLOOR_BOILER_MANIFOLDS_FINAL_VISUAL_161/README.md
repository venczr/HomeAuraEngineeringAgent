# D161 - два коллектора на одной стене котельной

На плане первого этажа K1 и K2 показаны как две пары реальных гребёнок: подача с расходомерами и обратка с клапанами. K2 перевёрнут на 180 градусов, поэтому его петлевые выходы направлены вверх. Оба узла размещены на одной внутренней стене котельной.

На мансарду предусмотрены две независимые ветви: шесть петель по полу под лестницей, вверх по дальней стене и через стену в гардеробную; восемь петель через отдельную проходку перекрытия из котельной в правую половину. Проектные длины с 3-м подъёмом - 56,2-76,2 м.
