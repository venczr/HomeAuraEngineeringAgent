# D160 · два коллектора в котельной и две ветви мансарды

K1 и K2 стоят рядом на одной внутренней стене котельной. K2 развёрнут патрубками вверх; расходомеры и клапаны остаются в обслуживаемой ориентации. Левая группа мансарды идёт по полу первого этажа под лестницей, поднимается по дальней стене и выходит в гардеробную. Центральная и правая группы получают отдельную внутреннюю проходку непосредственно из котельной.

Большая спальня мансарды разделена на четыре короткие регулярные улитки: это сохраняет длины 40-80 м с учётом 3-м подъёма и уменьшает пустоты. Стены теперь имеют отдельную толщину 100/200/400 мм, окна являются отдельными голубыми объектами редактора.
