# D047 — векторный контракт холла мансарды

Десять исходных векторных стен образуют одну вогнутую цепочку. По осям её площадь 39.857 м², что отличается от напечатанных 39,9 м² на -0.043 м². Эта величина используется только для сверки источника. Для черновой трассировки взяты внутренние грани: 39.531 м²; после вычитания консервативного лестничного проёма остаётся 35.874 м². Пороговые участки, монтажный зазор, покрытие, транзиты и полные контуры не приняты. D045/D046 сохранены как промежуточные исторические кандидаты.
