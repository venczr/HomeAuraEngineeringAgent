# D070 — аудит по прослеженным полосам перегородки

Вместо одного условного прямоугольника использованы три полосы, каждая построена по одной общей грани path 579 и своей противоположной грани paths 425, 910 или 283. Диапазон 9300–15400 мм явно является окном аудита диагностических ног D058, а не заявленной высотой стены.

Длинные продольные части A-C12 supply/return и A-C13 supply остаются REWORK. A-C13 return классифицирована отдельно как короткий поперечный кандидат; наличие реального проёма, порога, гильзы и конструкции ещё не доказано.
