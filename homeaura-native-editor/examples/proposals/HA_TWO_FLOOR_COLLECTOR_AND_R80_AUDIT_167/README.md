# D167 · коллекторы и R80

Коллекторы теперь отображаются в масштабе справочного 12/11-контурного оборудования, но изделие ещё не выбрано. Проверка R80 анализирует место для касательных на каждом сегменте: между двумя поворотами нужно минимум 160 мм. Сервис K2 проходит, F1-C14 и десять мансардных осей перечислены как REWORK.
