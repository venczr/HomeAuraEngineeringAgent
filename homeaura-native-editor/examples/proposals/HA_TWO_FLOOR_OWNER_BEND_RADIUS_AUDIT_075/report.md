# D075 — проверка радиуса изгиба 80 мм

Для каждого прямого сегмента рассчитан запас касательной: один радиус 80 мм на каждый соседний поворот 90°. Все 13 регулярных тел мансарды проходят локальную проверку; их минимальные сегменты 200 мм достаточны для двух соседних касательных по 80 мм.

У диагностических планарных фрагментов A-C09, A-C08 и A-C10 обнаружено по одному 100-мм стыку между двумя поворотами, где требуется минимум 160 мм. Эти стыки остаются схемой и должны быть перестроены при физической трассировке. Уменьшение радиуса прогревом не учитывается.
