# D137 — самодостаточная привязка шлюзов к состоянию протяжки

Все обязательные входы пяти шлюзов теперь находятся внутри одного объекта `readiness_inputs`; переход `S_PREPARATION → S_PULL_RELEASE` использует исходные идентификаторы D132. Неизвестные размеры, защитный слой, заделка, определение R80, фактическая труба, инструмент, изоляция и метод испытания остаются незаполненными. Поэтому гибка, протяжка, заделка и строительство не разрешены.
