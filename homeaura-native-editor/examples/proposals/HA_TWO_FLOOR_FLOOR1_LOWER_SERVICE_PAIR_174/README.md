# D174 · сбалансированная пара F1-R08 с явными транзитами

D174 заменяет только C01/C02. Сплошные диапазоны — отопительное тело, пунктирные промежутки — транзит; поэтому стены пересекают только короткие перпендикулярные трассы. Три трубы у наружных стен и под окном видимы, коротких 100-мм П-разворотов нет, R80 нарушений у изменённой пары нет.

Sharp-axis proxy: 98.226%. С физическими дугами R80: 96.817%, худшая контрольная точка 174.6 мм; все ближе 200 мм. Номинальные округлённые длины: F1-D171-C02=54.946 м, F1-D171-C01=53.980 м; разброс 0.966 м.

Это ещё не весь готовый этаж: 3D-рампы 70/108 мм и короткие штуцеры коллектора не материализованы, а в неизменённых C03-C13 остаются 16 старых нарушений R80.
