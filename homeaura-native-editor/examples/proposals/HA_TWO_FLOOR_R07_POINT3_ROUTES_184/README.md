# D184 · два непрерывных Point3-маршрута комнаты R07

D184 изменяет относительно официального D183 только C03 и C04. Их BODY дословно совпадает со строгой проверенной R07-парой: три оси по 100 мм у W008/WIN02, далее согласованное поле и компактное заполнение центра. Через стены проходят только TRANSIT; все изменения высоты оформлены S-изгибами R80.

Физические R80-длины: 48.612 / 50.543 м; разброс 1.931 м. Покрытие BODY: 96.262%, максимум 200 мм, превышений нет. Все 12 касаний wall-solid принадлежат TRANSIT и перпендикулярны стенам; в одном 300-мм окне не более трёх осей.

Физические XYZ-хвосты до Eurocone не материализованы. Поэтому collector_continuous=0, complete_K1=0, гильзы не добавлены и installation_ready=false. Последним AXIS на первом этаже остаётся C12.
