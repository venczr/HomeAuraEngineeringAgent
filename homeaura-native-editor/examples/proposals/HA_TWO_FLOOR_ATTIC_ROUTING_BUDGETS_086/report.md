# D086 — скрининг запаса длины для 12 контуров мансарды

После перестройки C01 все двенадцать оптимистических нижних оценок лежат в диапазоне 47.1–73.9 м. Наименьший запас до практической цели 78 м остаётся у A-C07: 4.1 м. Это не полные маршруты: расчёт использует одну абстрактную точку K2 и манхэттенские расстояния без препятствий, реальных портов, дуг R80, местных вертикальных вводов и гидравлики. Блок предназначен только для приоритета трассировщика: A-C07 строить первым и не расходовать его запас на необоснованные обходы.
