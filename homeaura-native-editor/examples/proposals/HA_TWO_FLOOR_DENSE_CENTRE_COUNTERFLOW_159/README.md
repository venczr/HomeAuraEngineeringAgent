# D159 · плотные центры улиток

Без изменения архитектуры и оси R1 перестроены только A-C01, A-C04 и длинный холловый A-C07. В последнюю ответную рамку добавлен допустимый 200-мм центральный проход, поэтому крупные пустые сердцевины уменьшились. Длины с подводками: A-C01 58,6 м; A-C04 78,0 м; A-C07 77,6 м. K2 остаётся на 400 мм от трубы и на 100 мм от монтажной зоны.
