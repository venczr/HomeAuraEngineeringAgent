# HA_TWO_FLOOR_LOCAL_GROUP_013

D013 сохраняет без изменений три проверенные полилинии D012 и исправляет доказательный пакет: pipes-only viewport теперь охватывает все точки, S/R подписаны отдельно, граница K1 явно включающая. Топология и длины проходят, но локальное покрытие не принимается: приближённая оценка по длине тел 35.52 из 56.80 м² (62.5%). Следующий блок должен использовать не менее четырёх контуров.
