# D171 · аналог ручного ACCEPTED-эталона владельца

Перекомпонован первый этаж по сохранённой ручной геометрической грамматике владельца. В кухне-гостиной теперь три крупных совместных поля вместо четырёх дробных. У наружных стен сохраняются три оси 100/200/300 мм, затем поле 200 мм. Отопительные тела не входят в стены; будущие подводки K1 будут отдельным слоем и только им разрешено пересекать стены.
