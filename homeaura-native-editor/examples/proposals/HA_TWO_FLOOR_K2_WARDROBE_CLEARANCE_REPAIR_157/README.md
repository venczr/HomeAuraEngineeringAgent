# D157 · освобождение монтажной зоны K2

Исправлена физическая ошибка D155/D156: K2 больше не лежит на трубе A-C01. Гардеробная улитка уменьшена только с восточной стороны, её расчётная длина стала 52,2 м с подводками. У K2 оставлен кандидат монтажной зоны 600×1000 мм; 11 остальных мансардных контуров, первый этаж и ось R1 сохранены.
