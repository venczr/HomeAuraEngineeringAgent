# D097 — повороты двух магистралей Ø32

Для переходов горизонталь–стояк у подачи и обратки выбран проектный фитинг Uponor S-Press PLUS 32-32, арт. 1070526. Официальные размеры: плечи l1=l2=51 мм, z1=z2=23 мм. Расчётно предусмотрены четыре угольника — по два на каждую магистраль.

Радиус R80 относится только к петлевой трубе Ø16. Магистраль 32×3 мм не греется и не сгибается по этому радиусу. Точная трасса, эквивалентные гидравлические длины, соединение у K1 и ведомость закупки пока не утверждены.
