# HomeAura — пообъектная диагностика

Версии этого обновления:

- AutoCAD-плагин: `1.1.0.0`
- HomeAura API: `0.5.0`

## Что добавлено

- `HA_SYNC_MODEL` передаёт по каждому объекту `Handle`, тип, слой,
  центр и геометрические границы.
- `HA_ANALYZE_MODEL` работает с новым маршрутом `/analyze` без
  тестового JSON в теле запроса.
- `HA_FIND_REMOTE_OBJECT` получает из отчёта вероятную удалённую
  геометрию, выделяет найденные объекты по `Handle` и приближает экран.
- Команда ничего не удаляет: решение об удалении остаётся за
  пользователем после визуальной проверки.

## Установка

1. Заменить `C:\AI\HomeAuraEngineeringAgent\agent\api.py` файлом
   `api.py` версии `0.5.0`.
2. Открыть `HomeAura.AutoCAD.Agent.sln` в Visual Studio.
3. Выбрать конфигурацию `Debug | x64` и выполнить
   `Сборка → Пересобрать решение`.
4. Перезапустить AutoCAD и загрузить новую DLL командой `NETLOAD`:
   `HomeAura.AutoCAD.Agent\bin\x64\Debug\HomeAura.AutoCAD.Agent.dll`.

## Проверка

В чертеже `Test_01.dwg` последовательно выполнить:

1. `HA_STATUS` — версия плагина должна быть `1.1.0.0`.
2. `HA_API_STATUS` — версия API должна быть `0.5.0`.
3. `HA_SYNC_MODEL` — создаёт новый снимок с пообъектными данными.
4. `HA_ANALYZE_MODEL` — показывает `Handle`, тип и слой вероятного
   удалённого объекта.
5. `HA_FIND_REMOTE_OBJECT` — выделяет объект и приближает его.
