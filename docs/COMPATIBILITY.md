# Совместимость компонентов

Версии AutoCAD-плагина и Python API имеют независимую нумерацию.

| AutoCAD-плагин | Python API | rooms format | AutoCAD | MagiCAD | Возможности |
|---|---|---|---|---|---|
| `1.2.0.0` | `0.6.0` | `1.1` | 2024 / .NET Framework 4.8 | 2024 UR-2 | Boundary для LWPOLYLINE и планарной SimplePoly Polyline3d, точные площадь/периметр, приоритет MagiCAD-R |
| `1.1.0.0` | `0.5.0` | `1.0` | 2024 / .NET Framework 4.8 | 2024 UR-2 | экспорт и синхронизация данных маркеров |

API `0.6.0` читает старые `rooms.json` формата `1.0`, в которых нет
`Boundary`, `FoundBoundaryCandidates` и диагностических полей.

Плагин `1.2.0.0` отправляет формат `1.1`. Для полного набора данных
рекомендуется API `0.6.0`; поля старого контракта при этом сохранены.
