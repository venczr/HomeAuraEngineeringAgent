# Геометрия помещений

Модуль геометрии помещений появился в AutoCAD-плагине `1.2.0.0`
и API `0.6.0`. Он дополняет данные маркера MagiCAD точным контуром
AutoCAD, не меняя исходный DWG.

## Поддерживаемая геометрия

Рабочим контуром считается только замкнутая
`Autodesk.AutoCAD.DatabaseServices.Polyline` (`LWPOLYLINE`) из
пространства модели.

Плагин обнаруживает, но не использует как границу:

- открытые `Polyline`;
- `Polyline2d`;
- `Polyline3d`;
- `Region`;
- перечисленные типы внутри определений блоков.

Это ограничение намеренное. Неподдерживаемые объекты попадают в
диагностику, но из них не создаётся искусственный контур.

## Контракт Boundary

| Поле | Назначение |
|---|---|
| `SourceHandle` | Handle исходной AutoCAD Polyline |
| `SourceObjectType` | DXF-тип исходного объекта |
| `SourceLayer` | слой исходного объекта |
| `Vertices` | нормализованные вершины XYZ |
| `Vertices[].Bulge` | bulge исходящего сегмента |
| `Vertices[].SegmentType` | `Line` или `Arc` |
| `IsClosed` | логическая замкнутость AutoCAD Polyline |
| `ContourAreaDrawingUnits2` | точная `Polyline.Area` в единицах DWG² |
| `ContourAreaM2` | та же площадь в м² |
| `PerimeterDrawingUnits` | точная `Polyline.Length` в единицах DWG |
| `PerimeterM` | тот же периметр в метрах |
| `OriginalDirection` | направление до нормализации |
| `Direction` | направление после нормализации (`CCW`) |
| `DrawingUnits` | значение `Database.Insunits` |
| `MetersPerDrawingUnit` | коэффициент перевода единицы DWG в метры |
| `GeometrySource` | фактический источник геометрии |
| `Diagnostics` | валидность, допуски и сообщения проверки |

`NetAreaM2` сохраняет прежний смысл: это площадь из бинарных данных
маркера MagiCAD. Поле `MagiCadNetAreaM2` — явный совместимый псевдоним.
Вычисленная площадь находится только в `Boundary.ContourAreaM2`.

## Нормализация и проверка

Алгоритм:

1. считывает XYZ и bulge каждой вершины;
2. удаляет последовательные дубликаты с допуском `0,1 мм`;
3. не дублирует первую вершину в конце массива — замыкание логическое;
4. требует минимум три различные вершины;
5. нормализует направление до `CCW`, корректно обращая bulge;
6. проверяет самопересечения;
7. использует точные `Polyline.Area` и `Polyline.Length`;
8. дискретизирует только дуги для point-in-polygon и проверки
   пересечений с максимальным отклонением хорды `1 мм`.

Оба допуска экспортируются в единицах текущего DWG.

## Привязка к маркерам

Для позиции каждого маркера `MAGIROOMTAG` выполняется point-in-polygon.
Если маркер содержат несколько валидных контуров, выбирается контур
с минимальной точной площадью. Количество кандидатов и выбранный Handle
записываются в предупреждения помещения.

Если валидного контура нет, `Boundary` остаётся `null`, а данные
MagiCAD продолжают экспортироваться в прежнем формате.

## Команды AutoCAD

- `HA_DISCOVER_ROOM_BOUNDARIES` — read-only инвентаризация кандидатов,
  их Handle, типа, слоя, замкнутости, площади и маркеров внутри.
- `HA_EXPORT_ROOMS` — локальный экспорт `rooms.json` с Boundary.
- `HA_SYNC_ROOMS` — отправка расширенного контракта в API.

Перед экспортом нового чертежа сначала запускайте диагностическую
команду. Если границы представлены неподдерживаемым типом, расширять
поддержку следует отдельной задачей после изучения фактических объектов.
