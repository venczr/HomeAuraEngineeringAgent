# HomeAura — M2 preflight: max-gap200 и разворот p100/R80

Состояние: **M2 не закрыт.** Выполнены два изолированных геометрических эксперимента, ни один не принят как полная новая раскладка. Исходный M1a fixture и принятый ограниченный M1b не изменены.

## Более строгий максимум200

У исходного ручного эталона в углах рядом с фиксированными концами расстояние до оси равно sqrt(200²+100²)=223,606798 мм. Поэтому его нельзя назвать прошедшим max200.

Независимый агент построил точный локальный S-переход на обратке у верхнего левого угла и зеркальный на подаче у нижнего правого. Концы и касательные сохранены. Точные массивы в `terminal-transition-candidate.json`; новый fixture явно устанавливает максимум200.

| Проверка | Результат |
|---|---|
| Длина | 58 798,052687 мм |
| R≥80, G1, концы, стены, OD-clearance | Проходят |
| Сетка10 мм, sagitta0,001 мм | Максимум189,073 мм; верхняя оценка196,145019 мм ≤200 |
| Прежняя морфология / полевой шаг | Обе проверки Fail |
| Локальное расстояние между прямыми | 20 мм возле концов |
| Общий статус | PartialGeometryOnly, accepted_successor=false, export=false |

Это показывает физическую возможность закрыть углы при разрешённой тесной терминальной зоне. **Такое разрешение не принято:** nominal p200 нельзя молча заменить на20 мм. Нужен отдельный содержательный контракт подключения; переносить эти петли в отопительную раскладку нельзя. Более плотная сетка использована с явной Lipschitz-границей ошибки, а не для подбора удачных проб.

## Почему p100/R80 — отдельная топология

Прямая полуокружность между параллельными проходами100 мм имеет R50 и не выполняет Rmin80. Построен другой изолированный вариант из **трёх касательных дуг R80**:

- α = acos((p+2R)/(4R)) = 35,659088°;
- углы поворота: −α, +(180°+2α), −α;
- средняя дуга: 251,318175°;
- начало(0,0), касательная(+1,0); конец(0,100), касательная(−1,0).

Он проходит отдельную проверку концов, касательных, R80, непрерывности, стен и OD16 в явно свободном тестовом прямоугольнике. Добавление препятствия в область выступа отвергается. Длина только трёх дуг450,485329 мм.

**Требуемое свободное место:** ось выступает вперёд до173,273791 мм, в стороны до y=−30 и y=130 мм. С OD16 оболочка занимает x=−8..181,273791, y=−38..138 мм без учёта прямых подводок. Для отдельного зазора до стены80 мм эти габариты нужно дополнительно расширить на80 мм либо непосредственно проверить расстояния. Соседние трубы и реальные границы проверяются отдельно.

Эта схема не равна «добавить два поворота»: она требует трёх дуг, большого центрального угла и дополнительной площади. Средняя дуга выходит за грамматику M1b quarter/half-arc; accepted checker не ослаблялся ради её прохождения. Возможное разбиение дуги на части не доказывает подходящую морфологию.

## Воспроизведение и следующий gate

В окружении из M1a-v2:

```powershell
python m2-preflight/recheck_terminal.py
python m2-preflight/omega_u.py
```

Первый скрипт независимо пересчитывает сохранённый терминальный вариант; второй строит и проверяет изолированный разворот. Для иллюстрации: matplotlib3.10.8 и render_m2.py. Все входы/выходы сохранены, экспорт выключен.

Следующий gate — согласованный инженерный контракт переходных зон и испытание turn-envelope внутри реального разрешённого домена: без отмены p200 в поле и без скрытых тесных участков. Пока этого нет, M2 остаётся No-Go; реальные C05/C06 не получают нового статуса готовности. Восстановление OAuth Claude потребуется для предусмотренного project policy аудита, который в этом прогоне не состоялся.
