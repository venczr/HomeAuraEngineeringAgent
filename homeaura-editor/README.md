# HomeAura Floor Heating Editor

Локальный инженерный MVP для детерминированного расчёта и проверки контуров
водяного тёплого пола. Интерфейс не изменяет точки маршрута: каждая SVG
полилиния строится из точного `CircuitRoute.polyline`, который вернул Python-
движок и принял валидатор.

## Запуск

Из PowerShell в корне репозитория:

```powershell
.\homeaura-editor\Start-HomeAuraEditor.ps1
```

Сценарий запускает локальное ядро на `127.0.0.1:8000`, редактор на
`127.0.0.1:3000` и открывает браузер. Геометрия комнаты не отправляется во
внешние сервисы.

## Текущие границы MVP

- прямоугольная комната на сетке 100 мм;
- одна наружная горизонтальная стена: южная или северная;
- детерминированный выбор 1–3 контуров по Coverage Planner;
- точные валидированные контуры длиной 40–80 м;
- препятствия проверяются, но автоматический обход ещё не реализован;
- покрытие показывается только как оценка, полное покрытие не заявляется;
- исходные параметры можно сохранить/открыть как детерминированный JSON;
- свежий результат можно выгрузить как SVG и полный JSON-отчёт;
- гидравлика, насос, смесительный узел, диаметр трубы и нормативное
  соответствие не рассчитываются.

## Проверка

```powershell
python -m unittest tests/test_floor_heating_coverage.py tests/test_floor_heating_coverage_preview_api.py tests/test_floor_heating_preview_api.py
Set-Location homeaura-editor
npm.cmd test
```

Для append-only пакета контрольного проекта при запущенном редакторе:

```powershell
npm.cmd run artifacts:mvp
```
